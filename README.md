# Anvil

This is a fork of the [original Anvil](https://github.com/burkeholland/anvil) project [Burke Holland](https://github.com/burkeholland), adapted to provide native ports for Claude Code and Copilot.

The goal is to keep the functionality and spirit of Anvil while making it work seamlessly with both Claude Code and Copilot CLI environments. That said, a perfect 1:1 likeness with the original is not guaranteed or promised—there may be differences in behavior or implementation.

Use it at your own discretion and enjoy!

## Ports

Each port can be found in the respective branch:

- **Claude Code**: See the `claude` branch
- **GPT/Codex**: See the `codex` branch
